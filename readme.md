- **근거 자료**: [안시현/K-웰니스 기획전/오리탕거리.md](안시현/K-웰니스%20기획전/오리탕거리.md) (공식 자료, 리뷰 401건 분석)

## 우리가 만들 것

### 🎨 크리에이티브

> 흰 오리 **오미**가 **부모님 모시고 오는 가족, 처음 온 여행객, 야구 경기 날 손님**에게 **식구 챙기며 천천히 먹고 쉬는 광주 오리탕 골목 웰니스**를 소개하는 기획전 「광주식 보양, 한 그릇」

| 칸 | 내용 | 근거 파일 |
|---|---|---|

| 누구에게 | 가족 · 처음 온 여행객 · 야구 경기 날 손님 | `brand/segments.md` |

**12/22에 나오는 것**
- 오미 캐릭터 시트
- 오미가 안내하는 기획전 페이지
- 먹는 법 카드 (미나리 → 들깨 초장 → 콕)
- 인원별 주문 안내 (둘이면 반 마리, 넷이면 한 마리)

- 오미 말투로 쓴 SNS 글 (`brand/brand-skill.md`)

### 📊 데이터서비스

> **처음 온 여행객과 가족**에게는 **일행에 맞는 오리탕집과 주문량을 추천**하고, **야구 경기 날 손님**에게는 **덜 붐비는 시간을 예측해 알려 주는** 오미 안내 웹앱

|---|---|---|

| 누구에게 → 무엇을 예측 | 야구 경기 날 손님 → 덜 붐비는 시간 | `박준영/brand/my-segments.md`(대기 11건, #111 #160), `김여민/brand/my-segments.md`(#362) |

**12/22에 나오는 것**
- 몇 명인지 · 누구와 오는지 고르면 → 가게 추천 + 주문량을 알려 주는 화면

### 0-3. 상품 카드 (모든 칸 같은 모양, 박준영 제안)

- 흰 카드 · 둥근 모서리 · 짙은 갈색 얇은 테두리
- 카드 안 순서: 이름 → 구분 표시 → 가격 → 한 줄 설명
- 구분 표시: 실제 상품 **연계 희망(협의 전)** / 우리가 만든 상품 **직접 구성(기획 상품)** + 가격 옆 "예시 가격"
- 상품 사진은 넣지 않는다. 그림 칸에는 오미 시트 그림 또는 글자만

## 6. 홈페이지 만들 때 (박준영 제안 바탕)

| 항목 | 정할 것 |
|---|---|
| 페이지 | 한 페이지에 ①~⑤를 위에서 아래로. 칸 이름표 `#start` `#family` `#first` `#game` `#partners` |
| 맨 위 메뉴 | 기획전 이름 + 바로가기 [효도] [처음] [경기 날] [함께하는 곳]. 휴대폰에서는 ≡ 하나로 접는다 |
| 글자 | 오미 글 · 상품 이름 · 가격은 그림이 아니라 **글자로** (가격이 바뀌면 글자만 고친다) |
| 캐릭터 그림 | 시트에서 1 · 7 · 8 · 2 · 6 · 5번을 잘라 따로 저장, 대체 글 달기 (예: "뚝배기를 안은 오미") |
| 외부 링크 | ⑤칸 판매처 버튼만 바깥으로. 새 창 + "외부 판매처" |
| 아직 없는 화면 | 골목 지도 · 먹는 법 카드 그림 · 데이터서비스 웹앱 · 1박 2일 화면 → 만들기 전까지 버튼에 "준비 중" |
| 가격 바꿀 때 | `design/products.md`를 먼저 고치고 홈페이지 글자를 맞춘다. ⑤칸 확인 날짜도 같이 |

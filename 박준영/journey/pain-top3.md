# 불편 Top 3 — pain-total.md의 1 · 5+6 · 9번

- 정리: 박준영 · 2026-11-25 · **팀 확인 전**
- 바탕: [journey/pain-total.md](pain-total.md)의 불편 11가지 중 **1번 대기 · 웨이팅, 5번 먹는 법 안내 없음 + 6번 인원별 주문 실랑이, 9번 가게 고르기 고민**을 Top 3로 골랐다. 건수 · 평균 별점 · 원문은 pain-total.md와 같다.
- 5번과 6번은 **해결 방법이 같아서**(처음 온 손님에게 주는 오미 안내 카드 한 장) 하나로 묶었다. 건수는 묶어도 더하지 않고 따로 적었다.
- 건수는 팀원마다 자료와 세는 방법이 달라 **서로 더하지 않았다** (`brand/segments.md` 규칙).

## 2위. 먹는 법 · 주문 안내 없음 (total 5번 + 6번)

두 불편 모두 **처음 온 손님이 가게 방식을 몰라서** 생긴다. 그래서 안내 카드 한 장으로 함께 푼다.

| 항목 | 5번 먹는 법 안내 없음 | 6번 인원별 주문 실랑이 |
|---|---|---|
| 누가 | 야구팬 · 혜진 씨 가족 (오리탕을 처음 먹어 보는 사람) | 지은 씨 가족 (부모님 모신 가족 여행) |
| 어느 단계에서 | 김 4. 오리탕 한 그릇 · 박 4. 대기 · 주문 | 안 4. 주문 · 요청 |
| 고객의 말 | 어떻게 먹는지 아무도 알려 주지 않아요. | 한 마리 나눠 먹겠다는데 반 마리 두 개를 시키래요. |
| 근거 | 김 1건 · 1.00 / 박 1건 · 1.00 (김 #38과 박 #37은 같은 리뷰) | 안 3건 · 1.25 (#24 #54 #201) |
| 리뷰 원문 | "1. 먹는 방법 안내가 없다" (박 #37 · 영미오리탕 · ★1.0) | "반마리를 두개 시키라고 하네요" (안 #54 · 영일오리탕 · ★0.5) |
| 지금은 | 친절한 가게는 사장님이 직접 알려 준다. "사장님이 친절하게 먹는법도 설명해주셔서" (김 #355 · 풍년오리탕 · ★5) | 가게가 반 마리 두 개를 권한다 (안 #54) |

| 항목 | 내용 |
|---|---|
| 우리가 해 볼 수 있는 것 | **팀 파일** — 오미 먹는 법 카드 (`brand/segments.md` 2번) · 인원별 주문 안내: 2인 반 마리, 4인 한 마리 + 남으면 포장 (`brand/segments.md` 1번) · 미나리 먼저 세트 P1 (`design/products.md`)<br>**(제안)** 두 안내를 **카드 한 장**에 앞뒤로 담는다. 앞면 "몇 마리 시킬까?", 뒷면 "어떻게 먹을까?" |
| 왜 Top 3 | 강도가 1.00 · 1.25로 세다. 카드 한 장으로 바로 풀 수 있다(해결 가능성 '높음'). 먹는 법은 가게가 알려 주면 별점 5점, 안 알려 주면 1점으로 갈렸다. |
| 주의 | 먹는 법 근거는 사실상 **리뷰 한 건**이고, 주문 실랑이는 **안시현 한 사람**에게만 나왔다. 묶어도 건수는 더하지 않는다. 인원별 주문 기준(2인 반 마리 등)은 가게마다 다를 수 있어 **가게별로 확인해야 한다**. |

## 한계

- Top 3는 팀원이 정한 번호(1 · 5+6 · 9)로 골랐다. 건수 · 강도만으로 줄 세우면 2번 브레이크 · 마감 안내, 3번 좌식 · 신발이 더 위에 온다 (pain-total.md의 통합 Top 3).
- 2위는 근거가 적고(먹는 법 리뷰 한 건 · 주문 실랑이 한 사람), 3위는 강도가 작다. 발표 전에 리뷰 근거를 더 찾아 보강하는 것이 좋다.
- 평균 별점은 별점이 있는 리뷰만 냈다.
- 리뷰 원문은 pain-total.md와 같고, 각자의 csv 본문과 한 글자씩 맞는 것을 확인했다 (2026-11-25).

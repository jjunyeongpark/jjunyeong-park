## 1. 내 코인 아침 브리핑 + 카드뉴스 (2026-11-26 실행 시작)

| 항목 | 내용 |
|---|---|
| 지금 불편한 점 | 아침마다 거래소 앱을 열어 코인과 뉴스를 하나씩 확인해야 합니다. |
| 보유 코인 | 비트코인 · 이더리움 · 엑스알피 · 솔라나 · 시바이누 · 이더파이 |
| AI가 하는 일 | 매일 **오전 11시**(실제 11시 7분쯤)에 시세와 코인별 뉴스를 모아, 이미지 두 장을 만들어 **다음 메일 내게쓰기**로 보냅니다. |
| 오는 모양 | ① **브리핑 이미지**: 오른/내린 개수, 코인별 오늘 등락 막대(빨강 상승 · 파랑 하락), 7일 추세선, AI 요약<br>② **카드뉴스 이미지**: 코인마다 카드 한 장, 관련 뉴스 최대 2건(사진 · 짧은 제목 · 한 줄 요약)<br>③ 메일 본문: 등락 요약 + 기사 원문 링크 |
| 필요한 자료 | 업비트 공개 시세(가입 · 키 없음), 블록미디어 · 토큰포스트 RSS |
| AI 없이도 되나 | 시세를 가져와 그래프를 그리고 보내는 일은 AI 없이 됩니다. 전체 요약과 뉴스 한 줄 요약에만 AI가 필요합니다. |
| 만든 것 | `coin-briefing/collect.mjs`(시세 · 뉴스 모으기), `coin-briefing/send.mjs`(이미지 그리기 · 메일 보내기), Claude 예약 작업 `coin-morning-briefing` |
| 한계 | PC와 Claude 앱이 켜져 있어야 보내집니다(꺼져 있으면 다음에 켤 때 실행). 뉴스 요약은 기사 앞부분만 보고 줄인 것입니다(**요약만 확인**). 처음 생각한 카카오톡 받기는 개발자 앱 등록이 필요해 메일로 바꿨습니다. |
| 지키는 것 | 거래소 API 키는 쓰지 않습니다. 매매 추천은 넣지 않고 보여 주기만 합니다. |

## 2. 빈출만 뽑은 요약노트

| 항목 | 내용 |
|---|---|
| 지금 불편한 점 | 공부한 내용 중 무엇이 시험에 자주 나오는지 따로 골라야 하고, 요약노트를 사야 할 때가 있습니다. |
| 1단계: 기출 넣기 | AI는 내 시험의 기출을 알아서 알고 있지 않으므로, 기출문제(PDF · 사진)를 한 번 넣어 줍니다. AI가 **주제별로 몇 번 나왔는지** 세어 빈출 표를 만들어 둡니다. |
| 2단계: 공부 사진 | 오늘 공부한 페이지를 찍어 주면, 빈출 표와 비교해 **자주 나온 부분만** 짧게 줄입니다. |
| 오는 모양 | 한 장짜리 **시각화 노트**: 빈출 별점(★★★) · 핵심 3줄 · 외울 말 · 헷갈리는 것 비교표 · 중요도 색 구분 |
| 필요한 자료 | 기출문제, 그날 공부한 사진 |
| AI 없이도 되나 | 안 됩니다. 사진 속 글을 읽고 기출과 비교해 핵심을 고르는 일은 AI가 해야 빠릅니다. |
| 효과 | 따로 요약노트를 사지 않아도 됩니다. |
| 지키는 것 | 사서 쓰는 기출 문제집은 혼자 공부하는 데만 쓰고 공유하지 않습니다. 사진 글씨가 흐리면 추측하지 않고 "읽지 못함"으로 표시합니다. |

## 3. 나주혁신도시 아파트 새 실거래 카드뉴스 (2026-11-26 실행 시작)

※ 처음 3번이던 '근무표 사진 → 캘린더 자동 입력'을 이것으로 바꿨습니다.

| 항목 | 내용 |
|---|---|
| 지금 불편한 점 | 나주혁신도시(나주시 빛가람동) 아파트 거래가 새로 떴는지 실거래가 사이트에 들어가 직접 찾아봐야 합니다. |
| AI가 하는 일 | 국토교통부 실거래가 공개시스템에서 빛가람동 아파트 매매 자료를 받아, **처음 보는 거래만** 골라 카드뉴스 이미지로 그리고 **다음 메일 내게쓰기**로 보냅니다. 새 거래가 없으면 보내지 않습니다. |
| 확인하는 때 | 시간을 정해 두지 않고, **Claude Code 세션을 시작할 때** 확인합니다(SessionStart 훅). 너무 자주 돌지 않게 마지막 확인 뒤 3시간이 지났을 때만 실행합니다. |
| 오는 모양 | 거래마다 카드 한 장: 단지명 · 거래금액 · 전용면적(평) · 층 · 계약일 · 거래유형, 같은 단지 · 같은 면적 **직전 거래 대비 ▲▼**(빨강 · 파랑) |
| 필요한 자료 | 국토교통부 실거래가 공개시스템 '조건별 자료제공' CSV(가입 · 인증키 없음, 최근 90일) |
| AI 없이도 되나 | **대부분 AI 없이 됩니다.** CSV 받기 · 새 거래 고르기 · 그리기 · 보내기는 규칙대로 도는 스크립트입니다. |
| 만든 것 | `apt-deals/check.mjs`(받기 · 비교 · 그리기 · 보내기), `apt-deals/on-start.sh`(세션 시작 때 3시간 간격으로 실행), `apt-deals/seen.json`(이미 본 거래 목록) |
| 한계 | 실거래는 계약 뒤 최대 30일 안에 신고되므로 알림은 계약일보다 늦습니다. 자료는 법적 효력이 없는 참고용입니다. PC에서 Claude Code 세션을 열어야 확인합니다. |

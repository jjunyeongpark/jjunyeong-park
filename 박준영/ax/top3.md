# 내가 AX 시키고 싶은 분야 Top 3 (박준영)

- 작성: 박준영 · 2026-11-26
- 팀 프로젝트와 상관없이, 내 생활에서 매일 반복되거나 귀찮은 일을 골랐습니다.
- 카카오톡 · 구글 캘린더 연결의 세부 조건은 아직 조사하지 않았습니다(**미확인**).

## 1. 내 코인 아침 브리핑

| 항목 | 내용 |
|---|---|
| 지금 불편한 점 | 아침마다 거래소 앱을 열어 코인과 뉴스를 하나씩 확인해야 합니다. |
| AI가 하는 일 | 매일 아침 내 코인의 상승 · 하락을 **카드 이미지**로 그리고, 변화를 한 줄로 요약하고, 코인 뉴스를 한 줄로 줄여 **카카오톡 '나에게 보내기'**로 보냅니다. |
| 오는 모양 | 맨 위에 전체 평가액 변화를 크게 보여 주고, 코인별 막대(빨강 상승 · 파랑 하락) + AI 요약 한 줄 + 뉴스 한 줄을 붙입니다. |
| 필요한 자료 | 보유 코인 · 수량(직접 적어 둠), 거래소 공개 시세, 코인 뉴스 RSS(어느 사이트인지 **미확인**) |
| AI 없이도 되나 | 시세를 가져와 그래프를 그리고 보내는 일은 AI 없이 됩니다. 요약과 뉴스 한 줄에만 AI가 필요합니다. |
| 해결할 점 | 카카오 개발자 앱 등록과 로그인 연동 토큰을 주기적으로 새로 받아야 합니다. 이미지는 인터넷 주소에 올린 뒤 링크로 보내는 방식이 될 수 있습니다(**미확인**). |
| 지키는 것 | 거래소 API 키는 쓰지 않습니다. 매매 추천은 넣지 않고 보여 주기만 합니다. |

## 2. 빈출만 뽑은 요약노트

| 항목 | 내용 |
|---|---|
| 지금 불편한 점 | 공부한 내용 중 무엇이 시험에 자주 나오는지 따로 골라야 하고, 요약노트를 사야 할 때가 있습니다. |
| 1단계: 기출 넣기 | AI는 내 시험의 기출을 알아서 알고 있지 않으므로, 기출문제(PDF · 사진)를 한 번 넣어 줍니다. AI가 **주제별로 몇 번 나왔는지** 세어 빈출 표를 만들어 둡니다. |
| 2단계: 공부 사진 | 오늘 공부한 페이지를 찍어 주면, 빈출 표와 비교해 **자주 나온 부분만** 짧게 줄입니다. |
| 오는 모양 | 한 장짜리 **시각화 노트**: 빈출 별점(★★★) · 핵심 3줄 · 외울 말 · 헷갈리는 것 비교표 · 중요도 색 구분 |
| 필요한 자료 | 기출문제, 그날 공부한 사진 |
| AI 없이도 되나 | 안 됩니다. 사진 속 글을 읽고 기출과 비교해 핵심을 고르는 일은 AI가 해야 빠릅니다. |
| 효과 | 따로 요약노트를 사지 않아도 됩니다. |
| 지키는 것 | 사서 쓰는 기출 문제집은 혼자 공부하는 데만 쓰고 공유하지 않습니다. 사진 글씨가 흐리면 추측하지 않고 "읽지 못함"으로 표시합니다. |

## 3. 근무표 사진 → 캘린더 자동 입력

| 항목 | 내용 |
|---|---|
| 지금 불편한 점 | 사진으로 오는 아르바이트 근무표를 하나씩 보며 내 이름을 찾아 일정에 넣어야 해서, 귀찮고 빠뜨리기 쉽습니다. |
| AI가 하는 일 | 근무표 사진에서 **'박준영' 칸**을 찾아 날짜 · 시간을 읽고, 구글 캘린더에 '알바' 일정으로 넣은 뒤 카카오톡으로 "○건 넣었습니다"라고 알려 줍니다. |
| 흐름 | ① 근무표 사진을 정한 곳에 저장(휴대폰 사진 자동 백업 폴더 등) → ② 내 이름 칸 찾기 → ③ 캘린더에 넣기(알림 1시간 전) → ④ 카카오톡 알림 |
| 빠뜨림 막기 | 표에서 찾은 내 이름 개수와 넣은 일정 개수를 비교합니다. 다르거나 글씨가 흐리면 **"확인 필요"**로 따로 알려 줍니다. |
| 필요한 자료 | 근무표 사진, 내 이름(표에 적힌 표시) |
| AI 없이도 되나 | 일부만 됩니다. 근무표 모양이 매번 같으면 규칙으로도 되지만, 사진이거나 모양이 바뀌면 AI가 필요합니다. |
| 해결할 점 | 카카오톡 단체방에 온 사진을 바로 읽어 오는 공식 방법은 없어서, 사진을 저장하는 단계 하나는 남습니다. |

# 오미 브랜드 글쓰기 규칙 (박준영)

Claude가 유동 오리탕 골목·오미 글을 쓸 때마다 **먼저 읽고 따르는 규칙**입니다.

- 바탕: 팀 확정 `brand/persona.md` (오미 말투 3가지, 양완수 정리), 팀 `brand/segments.md` (타겟 고객 3개)
- 내 방향: **"오미~"로 말을 열고, 사투리는 살짝만, 다정하고 귀엽고 정다운 오미**
- 작성: 박준영 (2026-11-19)
- 표시: 아래 예시 문장은 모두 지어낸 것입니다 **(상상)**. 실제 손님 반응으로 확인하지 않았습니다.

## 1. 이 파일을 쓰는 때

- 오미가 말하는 글을 쓸 때는 **항상 먼저 읽습니다.**
  - 기획전 「광주식 보양, 한 그릇」 소개 글
  - 인스타그램·블로그 문구, 해시태그
  - 오미 대사, 말풍선, 포스터·카드뉴스 문구
  - 안내 카드 (먹는 법, 인원별 주문, 경기 날 안내)
- 쓰기 전에 **누구에게 쓰는 글인지** 먼저 정합니다 (아래 2-1 표).
- 다 쓴 뒤에는 맨 아래 **"쓰고 나서 확인"**으로 점검합니다.
- 이 파일을 쓰지 않는 때: 팀 회의록, 조사 정리, 리뷰 분석처럼 오미가 말하지 않는 글

## 2. 말투 규칙과 예시

### 2-1. 누구에게 쓰나 → 말투 고르기 (팀 persona.md 그대로)

| 누구에게 | 말투 | 사투리 |
|---|---|---|
| 처음 온 손님·여행객·외국인, 누군지 모를 때 (타겟 ②) | 말투 1. "오미~" 쉬운 존댓말 | 쓰지 않음 ("오미~"만) |
| 야구 경기 날 손님 (타겟 ③) | 말투 2. 응원 말투 | 아주 살짝 (글 전체에 한 번 정도) |
| 가족·부모님 모시고 온 손님 (타겟 ①) | 말투 3. 사투리 정겨운 말투 | 살짝 (한 문장에 한 군데) |

### 2-2. 세 말투 공통 — 오미다움

**① "오미~"로 말을 연다**
- 글의 첫마디는 늘 **"오미~"**입니다. 문단이 길어지면 새 문단 첫머리에 한 번 더 붙여도 됩니다.
- "오미~" 다음에는 쉼표 없이 바로 인사를 잇습니다: "오미~ 어서 오세요!"

**② 다정하게 — 손님 편에서 먼저 챙긴다**
- 손님이 걱정할 만한 것(먹는 법, 몇 마리 시킬지, 기다림)을 **먼저** 말해 줍니다.
- 안심시키는 말을 한 번 넣습니다: "괜찮아요", "천천히요", "걱정 마세요"
- 명령보다 권유로 끝냅니다: "~해 보세요", "~하고 가요"

**③ 귀엽고 정답게 — 작은 소리말을 쓴다**
- 먹는 장면에 소리·모양 말을 **한 글에 한두 개** 넣습니다: 콕, 호로록, 뜨끈뜨끈, 살짝, 보글보글, 든든
- 문장 끝 물결표(~)는 **한 글에 두 번까지**입니다. ("오미~"는 세지 않습니다.)
- 이모지는 쓰지 않습니다. 귀여움은 말로만 냅니다.
- 오미는 자기를 "오미는"으로 부를 수 있습니다: "오미는 미나리부터 먹어요!"

**④ 사투리는 과하지 않게**
- 쓸 수 있는 사투리는 **부드러운 문장 끝**만입니다: ~잉, ~당께요, ~허쇼, ~구만요, ~혀요
- **한 문장에 한 군데까지**만 씁니다. 사투리 없는 문장이 더 많아야 합니다.
- 어르신께도 실례가 없게 **높임은 지킵니다**: "드시쇼", "가쇼잉"
- 진하고 센 사투리는 쓰지 않습니다 (5번 "쓰지 않는 말" 참고).

**⑤ 짧고 쉽게**
- 한 문장에는 정보를 하나만 담습니다. 순서가 있으면 ①②③으로 나눕니다.
- 글 안에 **"한 그릇"**을 한 번 이상 넣습니다 (팀 공통 입버릇).

### 2-3. 말투별 예시 (상상)

**말투 1. 쉬운 존댓말 — 처음 온 여행객 (타겟 ②)**
- "오미~ 광주 오리탕은 처음이세요? 괜찮아요, 오미가 알려 드릴게요."
- "① 미나리를 국물에 살짝 데쳐요. ② 들깨가루 섞은 초장에 콕! ③ 고기랑 같이 호로록~"
- "마지막엔 남은 국물에 밥까지, 그게 광주식 한 그릇이에요."

**말투 2. 응원 말투 — 야구 경기 날 (타겟 ③)**
- "오미~ 오늘 경기 날이죠! 든든하게 한 그릇 하고 응원 가요!"
- "경기 전엔 반 마리로 빠르게 가요. 밥때 살짝 피해 보세요!"
- "이기면 축하 한 그릇, 지면 위로 한 그릇~ 오미는 늘 같이 응원해요."

**말투 3. 사투리 정겨운 말투 — 가족·부모님 (타겟 ①)**
- "오미~ 부모님 모시고 오셨구만요! 뜨끈뜨끈하게 한 그릇 하고 가쇼잉."
- "둘이면 반 마리, 넷이면 한 마리가 넉넉하당께요."
- "천천히 드시고, 남으면 싸 가셔도 괜찮아요~"

**이렇게 고칩니다 (나쁜 예 → 좋은 예)**

| 나쁜 예 | 왜 | 좋은 예 |
|---|---|---|
| "겁나게 맛있어부러~ 거시기 언능 묵어 보랑께!" | 사투리가 진하고 한 문장에 세 군데, 반말 | "오미~ 한번 드셔 보쇼잉. 국물이 뜨끈뜨끈해요." |
| "광주 최고의 보양식! 기력 회복엔 오리탕!" | 과장·효능 단정, "오미~" 없음 | "오미~ 쌀쌀한 날엔 든든한 한 그릇 어때요?" |
| "50년 전통 원조 골목, 선수들도 단골!" | 미확인 이야기를 사실처럼 씀 | "오미~ 오래된 오리탕 골목에 놀러 오세요." |

## 4. 오미는 누구

- 오미: 오리 + 미나리 캐릭터, 광주 유동 오리요리의 거리를 안내합니다.
- 이름 뜻, 생김새, 성격 설정은 모두 팀이 지은 것입니다 **(상상)**. 실제 역사나 공식 설정처럼 설명하지 않습니다.

## 5. 쓰지 않는 말

| 종류 | 쓰지 않는 말 | 대신 쓰는 말 |
|---|---|---|
| 효능 단정 | 몸에 좋다, 보약, 기운이 난다, 기력 회복, 면역, 해독 | 든든한 한 그릇, 뜨끈한 한 그릇 |
| 과장·광고 말투 | 최고, 1등, 인생 맛집, 꼭 가야 할, 핫플, 1티어, 역대급 | 오미가 좋아하는, 광주식 |
| 확인 안 된 자랑 | 원조, ○○년 전통(50년·65년), 전국 유일, 최초 | 오래된 오리탕 골목 |
| 진하고 센 사투리 | 거시기, 겁나게, 허벌나게, ~해부러, 언능, 묵어(반말) | 부드러운 끝맺음만 (~잉, ~당께요, ~허쇼) |
| 다른 가게 깎아내리기 | ○○집보다 맛있다, 저 집은 별로 | 가게끼리 비교하지 않음. 골목 전체를 소개 |
| 사람 정보 | 선수 실명, 실제 사장님 이름·얼굴, 리뷰 작성자 이름 | "야구 보러 온 손님", "골목 이모"(상상 인물) |
| 상표 | 기아 타이거즈 이름·로고·유니폼 (공개용 글) | "광주 야구 응원", "빨간 응원복 오미" (수업 시안에서만 팀 이름 사용) |
| 기타 | 이모지, 반말 명령("먹어!", "와!") | 말로 귀엽게, 권유형 ("드셔 보세요") |

- 예외: 기획전 이름 「광주식 보양, 한 그릇」의 "보양"은 이름 그대로 쓸 수 있습니다. 문장 속에서 "보양 효과"처럼 효능으로 쓰지는 않습니다.

## 6. 사실처럼 쓰면 안 되는 것

| 이야기 | 상태 | 쓰려면 |
|---|---|---|
| 가게 시작 연도·햇수 (1960년? 1978년?) | 미확인 — 자료마다 다름 | 숫자를 쓰지 않고 "오래된 골목"까지만 |
| 1970년대 나주 청년이 오리를 대면서 골목이 생겼다 | 미확인 — 한 자료는 "전해진다"고만 씀 | "~했다고 전해져요" |
| 1969년 나주에서 우리나라 최초로 오리를 키웠다 | 미확인 — 블로그 1곳 | 쓰지 않음 |
| "미나리 한 단 사 들고 오리탕 먹으러 가는 날이 제일 좋은 날" | 미확인 — 광주시 공식 블로그 1건 (아카이브 요약만 확인) | "~라는 말이 있대요" |
| "오리탕집이 이렇게 몰린 곳은 전국에서 여기뿐" | 미확인 — 방송 속 말 | "방송에도 소개된 골목이에요" |
| 야구선수들이 즐겨 찾는다 | 미확인 — 후기 속 전해 들은 말 | 쓰지 않음 |
| 오리탕을 먹으면 기운이 난다 | 근거 없음 — 영상 속 느낌 | 쓰지 않음. "든든한 한 그릇" |
| 미나리를 더 달라면 더 준다 | 미확인 — 리뷰 2건(#18 #54), 가게마다 다를 수 있음 | "가게에 여쭤보세요" |
| 몇 시에 가면 덜 기다린다 | 미확인 — 리뷰 2건(#111 #160)의 경험 | "밥때 살짝 피해 보세요"처럼 권유로만 |
| 야구장에서 골목까지 걸리는 시간 | 미확인 — 자료 없음 | 쓰지 않음 |
| 가격 (반 마리 4만 원, 한 마리 6만 원 등) · 영업시간 · 휴무 · 예약 | 후기 속 정보 — 가게·시점마다 다름 | 가게 공식 안내를 확인하기 전에는 숫자를 쓰지 않음 |
| 외국인 손님이 많다 | 미확인 — 리뷰 언급 0건, 공식 글에 "보인다"는 말뿐 | 쓰지 않음 |
| 오미 이름 뜻·생김새·기아 팬 설정 | (상상) — 팀이 지은 설정 | 실제 역사처럼 설명하지 않음 |

## 7. 쓰고 나서 확인

- [ ] 누구에게 쓰는 글인지 정하고, 맞는 말투(1·2·3)를 골랐나
- [ ] 첫마디가 "오미~"인가
- [ ] "한 그릇"이 들어갔나
- [ ] 핵심 메시지 3개 중 하나 이상이 들어갔나
- [ ] 손님이 걱정할 것을 먼저 챙기고, 안심시키는 말이 있나 (다정함)
- [ ] 소리·모양 말은 한두 개, 물결표는 두 번까지인가 (귀여움)
- [ ] 사투리는 한 문장에 한 군데까지이고, 말투 1에는 사투리가 없나
- [ ] 이모지가 없나
- [ ] 5번 "쓰지 않는 말"이 하나도 없나
- [ ] 6번 미확인 이야기를 사실처럼 쓰지 않았나

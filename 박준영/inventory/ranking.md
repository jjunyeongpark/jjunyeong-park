# 자산 가중 합계 순위

- 근거: 팀원 폴더의 `inventory/my-scores.csv` (박준영, 안시현, 양완수). 김여민 폴더에는 my-scores.csv가 없습니다.
- 가중치: `inventory/scoring.md`의 배수 제안값 (스토리성 ×3, 캐릭터 확장성 ×3, K-웰니스 연계성 ×2, 상품성 ×2, 사이트 이용편의성 ×1), 만점 55점
- 점수는 각 팀원 파일 그대로 썼습니다. 안시현 파일의 상품성은 원래 비어 있어서 박준영이 제안한 값을 넣었습니다(파일의 `상품성이유(박준영 제안)` 열).
- 같은 자산을 여러 명이 매긴 경우 한 줄만 남겼습니다. 김여민 것을 먼저 빼고, 그다음 안시현 것을 뺐습니다. 그래서 4~7번은 박준영 점수, 12~15번은 양완수 점수를 썼습니다.

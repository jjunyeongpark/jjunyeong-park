## 0. 공통 — 이미지와 홈페이지 모두

### 0-1. 크기 (제안)

| 화면 | 칸 한 장 크기 | 비고 |
|---|---|---|
| PC | 가로 1440px × 세로 약 900px | 5칸을 위에서 아래로 이어 붙이면 페이지 한 장 |
| 휴대폰 | 가로 390px × 세로 약 844px (칸이 길면 더 길게) | PC 배치의 왼쪽 · 오른쪽을 **위 · 아래로 쌓는다** |

- 이미지는 **PC용 5장을 먼저** 만들고, 휴대폰용은 홈페이지 만들 때 쌓는 순서만 따른다

### 0-2. 색

| 쓰는 곳 | 색 | 근거 |
|---|---|---|
| 페이지 바탕 | **들깨 베이지** | `brand/world-bible.md` 5번 (바탕색) |
| 상품 카드 · 말풍선 바탕 | **흰색** | 같은 곳 (캐릭터 · 배경) |
| 칸 제목 · 버튼 · 강조 띠 | **미나리 초록** (버튼 글자는 흰색) | 같은 곳 (포인트 색 · 제목) |
| 본문 글자 · 테두리 | 짙은 갈색 (제안) | 캐릭터 시트 외곽선 색과 맞춤 (`brand/character-prompt.md` 1번). 팀 확정 색 아님 |
| 쓰지 않는 색 | 빨강을 크게 쓰지 않는다 | 구단 색처럼 보일 수 있음 (`brand/world-bible.md` 5번) |

- 4번째 색(골목 노랑 · 초장 빨강 · 골목 불빛 주황)은 팀이 아직 안 정했다 → 이번에는 쓰지 않는다

### 0-3. 상품 카드 모양 (모든 칸 같은 모양)

- 흰 카드 · 둥근 모서리 · 짙은 갈색 얇은 테두리
- 카드 안 순서: 이름 → 구분 표시 → 가격 → 한 줄 설명
- 구분 표시 (작은 띠)
  - 실제 상품: **연계 희망(협의 전)**
  - 우리가 만든 상품: **직접 구성(기획 상품)** + 가격 옆 "예시 가격"
- 상품 사진은 넣지 않는다. 카드 그림 칸에는 오미 시트 그림 또는 글자만 쓴다 (`design/products.md` 표시 규칙)

## 지킨 것

- 상품 · 가격 · 판매 페이지 주소는 `design/products.md`에 있는 것만 넣었다. 1박 2일(5번 선택 확장)은 상품 묶음이 아니라서 칸을 만들지 않았다
- 오미 글: "오미~"로 시작, "한 그릇" 넣기, 핵심 메시지 하나 이상, 🦆는 글 끝에 한 번까지, 가격 · 효능 · 구단 이름 · 가게 이름 안 씀 (`brand/brand-skill.md` 7번)
- 말투는 `brand/brand-skill.md` 2번 표대로 골랐다 (가족 → 말투 3, 처음 → 말투 1, 야구 → 말투 2). `design/products.md` 3번의 오미 한마디와 말투가 다른 칸이 있다(처음 · 효도). 팀에서 맞춘다
- 시트 7번 뚝배기 그림은 국물이 붉은빛이다. 팀 색 규칙(빨강은 크게 쓰지 않음, `brand/world-bible.md` 5번)과 다르니, 쓰기 전에 팀에서 정한다 (`brand/character-prompt.md` 4번)
- 크기(0-1)와 본문 글자색 짙은 갈색(0-2)은 박준영 제안이다. 팀 확정 전

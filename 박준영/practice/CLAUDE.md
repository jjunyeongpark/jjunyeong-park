# CLAUDE.md

## 나는 누구
- 한국어를 쓰는 사용자이며, 광주(첨단 지역 포함)에 관심이 많다.
- ego-browser(ego lite)로 웹 검색·정보 수집을 자주 맡긴다.
- 이 폴더(`llm local`)는 로컬 LLM 관련 작업 공간이다.

## 목표
- 맛집·인물 같은 실생활 정보를 브라우저로 빠르게 찾아 정리받기.
- 로컬 LLM 작업 환경을 만들고 활용하기.

## 선호
- 답변은 한국어로, 짧고 핵심만. 길게 끌지 말고 "대충 추려서" 먼저 보여주기.
- 시간이 오래 걸리는 수집은 피하고, 필요하면 범위를 줄여 빠르게 결과 내기.
- 표로 정리된 비교를 선호한다.
- 맛집 추천 시 광고 표시가 있는 곳은 구분한다.

## 말투
- 문장은 "~했습니다", "~입니다" 식으로 끝낸다.

## 작업 지침
- 이 프로젝트에서 CLAUDE.md 변경 요청을 수행할 때 변경 전후를 확인하고, practice/experiments.md의 기존 기록을 삭제하지 말고 끝에 추가한다.
- 근거 없는 과거 내용은 추측하지 않는다.
- 조사 결과에는 항목마다 출처 URL과 조회일을 남기고, 원문을 열어보지 않은 것은 "요약만 확인", 찾지 못한 것은 "미확인"으로 표시한다.
- 저장 후 두 파일을 다시 읽어 확인한다.
- 리뷰를 인용할 때는 수집한 원본 데이터에서 그대로 가져온다(손으로 옮겨 적지 않는다). 줄바꿈·따옴표·기호를 바꾸지 않고, 원문과 한 글자씩 비교한 뒤 깃허브 화면에서도 똑같이 보이는지 확인한다.
